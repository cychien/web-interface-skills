# Working in this repo

This repo is a collection of web design engineering principles, written as plain markdown. Nothing here is specific to any one agent or editor.

- The index is `skills/web-interface/SKILL.md`. Read it first.
- Individual principles are `skills/web-interface/principles/*.md`. Read only the ones the index points you to.
- To add or edit a principle, follow `CONTRIBUTING.md`. The structural rules there exist to bound context cost, so do not restructure around them.

Principle files must stay portable: plain markdown, no agent-specific syntax, no path variables, no references to a particular tool's mechanics.
