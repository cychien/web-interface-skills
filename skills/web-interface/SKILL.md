# Web Interface

## How to use this skill

1. Read **Always** below. It is short, universal, and applies to every UI change.
2. Scan the **Principles** index. Read `principles/<name>.md` only for the rows whose trigger matches what you are actually building.
3. When reviewing UI, walk the index as a checklist and report only the rows that are genuinely violated.

Do not read every principle file. The index exists so that you do not have to.
